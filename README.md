
# Glassdoor Salary Prediction

## Project Overview
This project uses Python and Machine Learning to analyze job listings and predict average salary estimates using the Glassdoor jobs dataset.

## Objectives
- Analyze salary trends across job titles and locations.
- Compare salary estimates across industries and company sizes.
- Explore the relationship between company ratings and salaries.
- Build a Machine Learning model to predict salary estimates.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Model
**Algorithm:** Random Forest Regressor

## Model Performance
- **R² Score:** 0.735
- **Mean Absolute Error (MAE):** 12.77K
- **Root Mean Squared Error (RMSE):** 17.56K

These results are based on the model's test dataset. Prediction errors remain, so estimates should not be treated as guaranteed salaries.

## Project Files
- `Glassdoor_Salary_Prediction.ipynb` — Complete analysis, visualizations, and Machine Learning workflow.
- `glassdoor_jobs.csv` — Dataset used for the project.

## How to Run
1. Open the notebook in Google Colab.
2. Upload or connect the dataset.
3. Run the notebook cells in order.
4. Review the visualizations and model evaluation results.
